# PDF MASTER

**FAST + SMOOTH + SHARP + LIGHTWEIGHT + COMFORTABLE UI**

PDF MASTER is a lightweight Android PDF reader focused on fast-feeling PDF opening, smooth continuous reading, high-quality text/vector rendering, smooth zoom + 2D pan, smart screen-fit minimum zoom, and comfortable premium UI.

## Master Requirements

The complete locked product requirements are maintained in [`docs/MASTER_REQUIREMENTS.md`](docs/MASTER_REQUIREMENTS.md).

## Development Rule

Every stage follows the locked four-step workflow:

1. **Step 1 — Build** the current stage completely.
2. **Step 2 — Verification 1** for errors and basic functionality/UI.
3. **Step 3 — Verification 2** for deep requirements, integration, performance, edge cases and UX.
4. **Step 4 — Fix + Pass** all discovered issues and only then mark the stage complete.

Do not skip stages or silently move ahead before the current stage passes its workflow.
